## About the site

A single responsive page built with **plain HTML, CSS and JavaScript**: no frameworks and no build step.
Hosted on **GitHub Pages**.

- Responsive layout (desktop, tablet and phone) with a mobile menu
- English / Portuguese switch and light / dark theme, both remembered between visits
- Job durations calculated automatically from start and end dates
- Project filters by category
- The menu highlights the section being read
- Subtle scroll animations (turned off for people who prefer reduced motion)
- Basic accessibility: semantic HTML, keyboard navigation and alt text

### Structure

```
.
├── index.html          # Page content (all sections)
├── assets/
│   ├── css/main.css    # Styles and color palette (CSS variables)
│   └── js/
│       ├── main.js     # Language, theme, menu, durations, filters and scroll effects
│       └── i18n.js     # Portuguese translations (English lives in index.html)
└── images/             # Project screenshots, logos and favicons
```

### Running locally

Nothing to install. Clone the repository and open `index.html` in your browser:

```bash
git clone https://github.com/MonykPenafor/monykpenafor.github.io.git
```

In VS Code, the **Live Server** extension reloads the page automatically while you edit.
