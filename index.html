01 · About

About me

I'm a Full-Stack Developer working in the C#/.NET ecosystem, with ASP.NET, SQL Server and Angular. My work covers the development, maintenance and continuous improvement of web systems and APIs.

Today I work on a large-scale ERP for the automotive sector, serving over 1,000 companies and about 12,000 users. I deliver new features, system integrations and business process improvements across different application layers, following SOLID, Domain-Driven Design and Clean Architecture.

I work in agile teams using Scrum and Kanban, write unit tests, review code and manage source control in Azure DevOps, and use and monitor CI/CD pipelines. I'm always looking to go deeper into software architecture and scalable solutions that balance technical quality with real business needs.
